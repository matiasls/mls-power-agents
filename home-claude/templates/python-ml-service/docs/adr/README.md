# Architecture Decision Records (ADRs)

This directory holds the architectural decisions made on this project.

- Naming: `NNNN-decision-in-kebab-case.md` (4-digit zero-padded sequence: 0001, 0002, ...).
- Write an ADR for: any non-obvious technical decision, any deviation from the global stack defaults (`~/.claude/CLAUDE.md`), anything a future dev would otherwise reverse-engineer.
- Do NOT write ADRs for routine implementation choices or things already documented in code.
- ADRs are immutable: if a decision changes, write a new ADR that supersedes the old one and update the old status to "Superseded by ADR-XXXX".

Template and full guidelines: skill `adr-writing` (template at `~/.claude/skills/adr-writing/resources/adr-template.md`).
