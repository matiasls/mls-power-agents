# Phase Gates

This directory holds the gate reports produced at the end of each phase.

Naming: `gate-<N>-<phase-name>.md`, e.g., `gate-0-discovery.md`, `gate-3b-architecture.md`.

Gate reports are produced by the `critic` subagent via the `/phase-gate` command.

For major gates (1, 2, 3B, 5), the report also includes a Devil's Advocate section.

See `~/.claude/skills/phase-gate/SKILL.md` for the full procedure.
