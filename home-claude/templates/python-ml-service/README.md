## Stack

- Python 3.11+
- uv (dependency management)
- FastAPI (HTTP server)
- Pydantic v2 (validation)
- pandas/polars + scikit-learn/XGBoost (model code — specifics depend on project)
- ruff + mypy (lint + types)
- pytest + pytest-cov (tests)

## Available commands

| Command | What it does |
|---|---|
| `make setup` | Create venv, install deps |
| `make dev` | Start FastAPI dev server (port 8001) |
| `make test` | Run pytest with coverage |
| `make lint` | ruff + mypy |
| `make format` | Auto-format with ruff |
| `make train` | Run training job |
| `make predict` | CLI prediction (smoke test) |
